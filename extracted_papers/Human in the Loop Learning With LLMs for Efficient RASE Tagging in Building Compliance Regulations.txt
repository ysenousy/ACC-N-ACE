executed manually, demanding significant time and labor. this work investigates the automation of the requirement, applicability, selection, and exception (rase) methodology for building regulatory tuning enhances model performance by training it on a specialized dataset, thereby improving structural and textual accuracy. progressive active learning, by iteratively incorporating expert feedback, further refines the accuracy of the model. the findings demonstrate substantial enhancements in both structural and semantic accuracies of the generated yaml files, underscoring the potential of integrating llms with active learning to streamline regulatory compliance automation. the methodologies and results presented here offer a comprehensive framework for advancing future research and limits inherent to gpt models, which are capped at 4096 tokens per generation. this strategy was essential for handling lengthy documents, typical of regulatory texts, that exceeded the models output capacity. the incremental prediction approach is detailed as follows: 1) initial input processing: the model begins by pro- cessing the initial segment of the regulatory text. this initial input is kept within the token limit, ensuring that the model can generate an output without truncation. 2) partial yaml generation: based on the initial input, the model generates a portion of the yaml output. this partial yaml segment fits within the token limits and represents a fraction of the complete conversion. 3) context reinsertion: the generated yaml segment is reinserted into the models context. this updated context includes both the initial regulatory text segment and the corresponding generated yaml. 4) subsequent input segmentation: the next segment of the regulatory text, following the initial segment, is appended to the updated context. care is taken to ensure that the combined context (previous context plus the next segment) remains within the token limit. 5) iterative generation: the model is prompted again to continue the yaml generation from where it left off. this iterative process involves repeatedly gener- ating new segments of the yaml output, reinserting them into the context, and appending subsequent text segments until the entire document is processed. 6) handling long documents: for particularly lengthy documents, this incremental approach ensures that the entire text is eventually converted into yaml format, with each segment processed and reintegrated methodically. this avoids issues related to token overflow and ensures continuity in the generated output. 7) evaluation of continuity and accuracy: at each step, the generated yaml segments are evaluated the for continuity and accuracy to ensure that 185298 volume 12, we present and discuss the results obtained from three experiments conducted to evaluate the performance of our system in generating yaml files from regulatory text. the evaluation is grounded in two primary metrics: structural similarity and text similarity, which are proposed and employed to comprehensively assess both the format and content of the generated yaml files. a. structural similarity the structural accuracy of the generated yaml files is evaluated using graph similarity metrics. each yaml file is converted to a graph representation where the nodes represent keys and values, and the edges represent the hierarchical rela- tionships between these elements. we employ the simgnn model [17], a neural network-based approach, to compute the similarity between the generated and reference graphs. this process begins with converting the generated yaml and the reference yaml into graph structures. initial node embeddings are then computed using graph convolutional networks (gcns), which aggregate information from neigh- boring nodes to produce a rich representation of the graphs structure. these node embeddings are further aggregated into a single graph-level embedding using a global context-aware attention mechanism, which computes a global context vector for the graph and uses it to weigh the importance of each node embedding. interaction scores between graph-level embeddings are computed using a neural tensor network (ntn). additionally, pairwise similarity scores between nodes of the two graphs are computed, and histogram features are extracted from these scores. finally, graph- level interaction scores and histogram features are combined using fully connected layers to produce a final similarity score. to quantify the structural differences between the gen- erated and reference graphs, we compute the graph edit distance (ged), which measures the minimum number of operations (node/edge insertions, deletions, and relabelings) required to transform one graph into the other. the ged is normalized and transformed into a similarity score ranging from 0 to 1 using the exponential function (x) = ex, where x is the normalized ged. b. text
